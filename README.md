## 🚀 Featured Projects

### 🎥 YouTube RAG — Video Q&A Assistant

> Ask questions about a YouTube video and get answers grounded in its transcript.

**Tech:** Python • LangChain • ChromaDB • Sentence-Transformers • Groq LLM • FastAPI

- Built a Retrieval-Augmented Generation application for YouTube video Q&A.
- Created an ingestion pipeline for transcript fetching, chunking, and embedding.
- Used `all-MiniLM-L6-v2` embeddings with ChromaDB for local vector storage.
- Implemented cosine-similarity retrieval of the top 5 relevant chunks.
- Generated grounded responses using a Groq-hosted LLM.
- Exposed `/ingest` and `/ask` REST endpoints using FastAPI.
- Added transcript source citations to the web interface.
